# Security Policy

## Supported Versions

Bugbase is in early development. Security fixes will be applied to the latest mainline version of the CLI.

## Reporting a Vulnerability

Do not open public GitHub issues for sensitive vulnerabilities.

Report security issues privately to `security@monodox.com`. Include:

- A clear description of the issue
- Steps to reproduce
- Impact assessment
- Affected versions or commit hashes
- Any suggested remediation

If the issue is confirmed, the team will validate it, coordinate a fix, and publish a responsible disclosure once users have a reasonable upgrade path.

## Scope

This policy applies to:

- The Bugbase CLI
- CI integrations maintained in this repository
- Security analysis and scoring behavior implemented by this project
